# check-skill

> **「 发出去之前，再帮你看一遍 」**

一篇稿子来回改了好几轮，读着已经挺顺了，真要发布时，心里还是会有几个问号：数据有没有写错？客户案例能不能公开？这句话会不会让人误以为我们拿到了官方背书？

check-skill 就是为这个时候准备的。把文章、新闻稿或方案交给它，让它帮你找出容易漏掉的问题，标出原文，再给出具体的修改建议。

## 好读的稿子，也值得再检查一次

它会从字句一路看到对外口径：

- **句子有没有问题:** 错别字、病句、搭配不当、指代不清，还有缩写、标点、数字和单位。
- **事情有没有说准:** 人员职务、机构名称、活动届次、专业术语、引用数据，以及前后能不能对得上。
- **标题有没有说过头:** 测试条件有没有交代清楚，局部结果是否被说成普遍结论，预期效果是否被写成既有成绩。
- **案例能不能公开:** 客户是否授权、业务是否涉及内部禁宣口径、技术表述是否容易被理解成合规保证。

举两个例子：一篇新品介绍，正文说续航 18 小时，参数表却写了 20 小时；一篇活动稿，把“蓝桥实验室主任”写成了“蓝桥研究院院长”。前者需要统一数据，后者需要核对机构名称和职务，不能只看句子顺不顺。

这些都是它会重点提醒你的地方，尤其适合 创业、AI、算力和硬科技公司的内容团队，在发稿前多做一轮检查。

## 修改建议，也要讲道理

审核时最让人头疼的，是把“这样写也许更好”说成“你这样写就是错的”。

check-skill 会尽量把话说清楚：能确定的错误，指出原因；需要查证的事实，告诉你还缺什么；属于表达习惯或风格选择的，留作讨论，不强行改掉你的写法。

舆情判断也一样。法律法规、公司的内部口径、媒体评论各有各的用途。明确有依据的风险会指出来，拿不准的会标为待核实、待讨论。

## 从你手上的这篇稿子开始

在支持加载 skill 的 AI 助手里，可以直接说：

> 请用 check-skill 审核这篇内容。把明确错误、待核实事项、对外宣传风险和可选优化分开列出，附上原文位置和修改建议。

支持 Word（`.docx`）、PDF、PPT（`.pptx`）、TXT 和 Markdown。也可以检查多份文件、对比新旧版本，或用自己的术语表统一用词。扫描 PDF 需要可用的 OCR 环境。

基础脚本负责提取内容和规则检查，AI 负责理解全文、核查事实和判断宣传口径。报告可以输出为 Markdown、JSON 或 Word。

脚本本身不会自动调用 AI 或联网，评分也只能作参考。完整审核需要在 AI 助手中按 skill 的流程完成。

## 让判断跟上行业变化

科技行业变化快，去年能用的数据，今年未必还合适。

你可以告诉 GPT 自己关注的行业、关键词和媒体，让它帮你整理监测范围。比如，把下面这段里的内容换成自己的需求：

> 我关注工业软件和智能制造，想跟踪工业传感器、设备维护、产品认证相关的政策和新闻。请帮我整理一份关键词清单，补充常见叫法，并推荐相关的官方与媒体来源。排除无关融资和消费电子新品，把这份范围写入 check-skill 的政策与行业热点参考记录。

如果你关注算力行业，也可以这样说：

> 我关注算力行业，想跟踪智算中心、算力租赁、推理成本、算电协同和数据中心能耗相关的政策与新闻。请帮我整理关键词及常见叫法，优先查主管部门的政策原文，并结合科技媒体的行业报道。排除只提到 AI、却与算力业务无关的内容；涉及价格或性能的数据，注明时间、单位和测试条件。把这份范围写入 check-skill 的政策与行业热点参考记录。

关键词确定后，再请 GPT 帮你设置更新频率：

> 请创建一个定时任务，每周一北京时间上午 9 点，按刚才的关键词查找最近一周的相关政策和新闻。保留标题、原文链接、发布日期，以及它为什么值得关注；把政策原文、新闻报道和评论分开列出。能够访问文件时，更新 check-skill 的 references/policy-watch.md；不能访问时，给我一份可以手动保存的整理结果。没有重要变化时不用提醒我，有影响宣传口径的变化或需要我判断的事项再通知。创建后告诉我实际设置的时间和任务状态；如果当前平台不支持定时任务，请明确说明。

这两段提示词都可以随时调整。关注领域变了，就让 GPT 更新关键词；想看得更勤或更少，也可以直接修改时间和频率。


## 给它一点背景，审核会更贴切

告诉它这份稿子准备发给谁、属于哪个行业，以及有哪些披露要求。例如，“青禾机器人”团队可以约定：未发布产品的照片暂不公开，合作方名称须经双方确认后使用。审核会结合这些背景给出建议，并将团队约定与法律要求分开说明。

涉及重要法规或发布决策的事项，仍应交给负责人员确认。

本项目基于既有的“文档审核（document-review）”skill 扩展，保留了原有的文档提取和基础检查脚本，重点补充了对外宣传口径、政策与媒体参考，以及更审慎的审核判断方式。

> 希望它可以让你的每一次审核，轻松一点点～
